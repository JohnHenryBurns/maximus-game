# 🎮 Maximus Game

A game by **Max**, age 9. Built from scratch. Nothing here is finished yet — that's the fun part.

**▶️ Play it:** https://johnhenryburns.github.io/maximus-game/

---

## Hi Max 👋

This is *your* repo. You get to decide what this game is.

Right now `index.html` is almost empty on purpose. It has just three things:
a **canvas** (a rectangle to draw on), a **game loop** (the thing that runs 60 times a
second), and a way to tell **which keys are being pressed**.

That's the skeleton of every video game ever made. Everything else — the player,
the enemies, the score, the explosions — is stuff you get to add.

## How to work on it

1. Open a terminal in this folder and type `claude`
2. Tell it what you want to build
3. Try stuff. Break stuff. Fix stuff.

Claude is your coding partner, not your butler. Ask it *why* things work.
If you don't understand a line of code, say **"explain that line to me"** — seriously, do this a lot.
Understanding your own game is the whole point.

## How to see your game

Double-click `index.html`. It opens in your browser. That's it — no setup, no waiting.

Changed something? Save the file and press **F5** to reload. You'll see it instantly.

## How to put it on the internet

```
git add .
git commit -m "made the player jump"
git push
```

Wait about a minute, then open the link at the top of this page. Your game is now
live on the actual internet and anyone in the world can play it. 🌍

## Stuck?

- **Nothing shows up?** Press `F12` in your browser and look at the "Console" tab.
  Red text = an error, and it tells you which line. That's not the computer being mean,
  that's the computer being helpful.
- **Broke something badly?** Nothing is ever really broken. Type `git status` and ask
  Claude to help you go back. Git is a time machine.
- **Out of ideas?** Ask Claude: *"give me three weird ideas for what to add next."*
